## 2. Screenshots Requirements

### Specifications
- **Quantity**: 2-8 screenshots (recommended: 8 for best presentation)
- **Format**: PNG or JPEG
- **Dimensions**:
  - Phone: 16:9 or 9:16 aspect ratio
  - Minimum: 320px
  - Maximum: 3840px
  - Recommended: 1080 x 1920 px (portrait) or 1920 x 1080 px (landscape)

### Recommended Screenshots (in order)

1. **Home Screen** - Category filters and attraction cards
2. **Attraction Detail** - Sigiriya with image gallery and details
3. **Interactive Map** - Sri Lanka with marked attractions
4. **Trip Planner** - Custom itinerary with multiple attractions
5. **Offline Maps** - Demonstrate offline functionality
6. **Multi-Language** - Show Sinhala/Tamil support

## 3. Graphic Assets

### App Icon
- **Size**: 512 x 512 px
- **Format**: PNG (32-bit with alpha)
- **Design**: Simple, recognizable, works at small sizes
- **Colors**: Use brand colors (Deep Ocean Blue #1565C0, Tropical Green #2E7D32)
- **Content**: Avoid text, use symbolic representation

### Feature Graphic
- **Size**: 1024 x 500 px
- **Format**: PNG or JPEG
- **Design**: Showcases app's main value proposition
- **Text**: Keep minimal, ensure readability
- **Content**: Sri Lanka landmarks, app name, tagline

**Suggested Content:**
```
[Background: Sri Lankan landmarks collage]
Serendib Guide
Discover the Island of Serendipity 🌴
300+ Attractions | 100% Offline | Multi-Language
```

### Promotional Video (Optional)
- **Length**: 30 seconds to 2 minutes
- **Format**: MP4 or MOV
- **Content**:
  - Show app navigation
  - Highlight offline functionality
  - Demonstrate key features
  - Include call-to-action
